FileKit — Mobile Web View

This is the real FileKit web app embedded at phone width — no phone chrome, no mockup. It uses its own responsive breakpoints, so the rail collapses and the bottom tab bar appears exactly as it will on a phone. Click into any tool (try Crop Pages or Convert Video) for the real workspace.

filekit.cc

Live & self-explanatory. Serve it with python serve.py then open http://127.0.0.1:8000/mobile-preview.html.
